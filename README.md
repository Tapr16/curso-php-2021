# Curso de PHP · 2021

Mis inicios en programación. Estos son los ejercicios que hice en un curso de PHP entre **febrero y marzo de 2021**, cuando tenía 16 años: una carpeta por clase, en el orden en que las fui haciendo.

Originalmente eran 21 repositorios separados. Los reuní aquí para tenerlos ordenados en un solo lugar. El código está tal como lo escribí en ese momento, sin correcciones.

## Cómo ejecutarlo

Necesitas PHP instalado. Desde la carpeta de cualquier ejercicio:

```bash
php -S localhost:8000
```

y abre `http://localhost:8000` en el navegador.
